# AI 提示词工作台（0.6.2）

用一句需求起草补充提示词，再用反馈改写；从选定的规范或反馈中提取规则。生成内容先成为候选，保存与启用分开。

## 三个入口

| 入口 | 使用方式 |
| --- | --- |
| 提示词与规则 → AI 创作 | 描述目标，可选带入当前草稿或材料，生成新方案 |
| 配置编辑器 → 按反馈优化 | 默认带入当前草稿及其引用规则，说明希望改善的问题 |
| 规则库 → AI 整理规则 | 粘贴规范或纠正意见，可选带入已有规则，生成规则候选 |

例如：“维护 Java 项目，中文回复，先定位代码再修改，改完验证，不要输出很长的计划。”不需要先把需求分别写进正文、附加规则和共享规则。

## 模型与材料

- 复用 DSH 已配置的供应商与模型，面板不需要重新填写 API Key。可在创作区选择供应商和模型；本次选择会保存在 AI 自己的设置中。
- 初始选择依次来自本次明确选择、AI 已保存模型、DSH 默认模型。未承诺自动跟随当前聊天尚未发送的新模型选择。
- 生成会把需求、所选材料及明确带入的草稿/规则发给所选模型服务。材料不会自动经过设置页的环境信息过滤；“隐藏具体值”不能替代材料检查。
- “按反馈再改一版”会带入前一候选。原先未勾选的当前草稿不会被隐式发送。
- 不自动扫描磁盘或全部聊天。可点击“本次实际使用的输入与来源”查看冻结的需求、材料、草稿及规则版本，不受后来编辑输入框影响。
- AI 生成的是 DSH 的补充段，辅助调用不启动 Agent 工具执行，也不自动把当前启用的补充段当作自己的系统指令。宿主其他 LLM 钩子仍可能观察或处理调用。

模型目录失败会显示提示；仍可使用已保存且有效的模型。没有 AI 服务时，原有编辑、导入导出和注入仍可用。AI 能力在本机 DSH 0.2.2-rc.1 上完成验证，需要宿主提供相应模型接口。

## 如何处理候选

生成完成后可以查看正文、附加规则、修改说明、待核实假设和最多两项待补充问题。候选标为“尚未验证效果”，不是模型评分或性能提升证明。

- **原稿与候选差异**：并排显示，短文本标记增加/删除行；文本较长时显示全文，不声称逐行高亮。
- **按反馈再改一版**：例如“更短，保留验证要求”，继续生成新候选；旧候选留在历史。
- **另存为新方案**：将正文和勾选规则一次提交为新配置，原配置与原共享规则保持不变，不自动启用。
- **仅替换正文与附加规则**：只改前端草稿，之后仍须保存。新共享规则不会提前写库，也不会偷偷改变已有 ruleIds。
- **保存所选规则**：规则提取候选可以只保存勾选规则，不新建配置、不改变启用项。

原稿被修改后，候选提示“基于旧输入”，替换草稿入口禁用；仍可比较后另存或重新生成。多窗口改变了原配置/规则时，保存采用返回冲突并保留候选。

当前启用配置由 DSH 进程共用。打开或编辑一个配置不会启用它；主动启用后，对该宿主之后的组装统一生效，不是只改变当前聊天。

## 共享规则如何采用

每条建议显示正文、来源依据、范围、理由及重复/冲突提示，可以批量勾选。

- 引用已有：只允许引用本次选定材料中的已有规则，沿用其保存内容与启用状态。
- 复制后修改：创建新规则，只有新方案的对应引用被替换；其他引用原规则的配置不受影响。
- 新建：创建所选规则；共享库本身不意味着全局注入，仍需配置引用。
- 文本完全重复的候选会去重；与所选已有规则仅空白差异的建议会转换成复用。语义冲突和模型提取依据仍是未验证建议。
- 新方案沿用带入草稿的原引用及规则段开关；没有带入草稿时采用默认开关。停用的已有规则不会因复用而自动启用。保存后可在编辑器调整。

项目标签/模型描述不代表已实现自动项目适用。一次性任务不应自动沉淀为长期规则，未知测试命令等仍应核对。

## 调用预算、失败和取消

普通创作每个任务最多两次辅助调用尝试：主请求及最多一次 JSON 格式修复。单次输出上限 4000 Token，整个任务 90 秒上限，每次输入最多 120000 UTF-8 字节（含格式修复的累计上限 240000 字节）。达到限制会停止或拒绝，原稿不变。

同一宿主内同时运行一个创作任务。界面显示调用尝试数、供应商返回的输入/输出 Token；缺少用量或价格时显示未知，不显示虚假的零成本。底层供应商重试与计费由其实现决定。

“取消生成”会尽力中断请求并阻止后续调用，已经派发的请求仍可能计费。关闭抽屉不取消任务，可重新打开从历史恢复。服务热加载或宿主重启后，未完成任务标为中断，不会自动继续调用。

模型拒绝、超时、空结果、工具请求、输出截断、两次结构失败都会显示错误，不把半截结果当作成功候选。

## 本地记录与清除

```text
DSH_HOME/prompt-lab/
  profiles.json                 # 已保存配置和规则，继续使用 schemaVersion 2
  settings.json                 # 原环境信息/渠道兼容设置
  studio/settings.json          # AI 模型引用，无 API Key
  studio/jobs/j-<UUID>.json      # 任务、冻结输入、来源、候选、采用记录
  studio/suites/s-<UUID>.json    # 测试集、修订号和重复使用记录
  studio/revisions/v-<UUID>.json # 资产保存前后完整快照及提交状态
```

保留最近 20 份终结任务，运行任务单独保留。仅保存用户选定输入和必要任务数据，不记录整个会话或模型思考过程；这些本地记录可能含材料原文，请按自己的数据要求管理。

“清除创作历史”删除本地任务/候选，包括其冻结材料和试跑输出；不删除已保存配置、规则、模型选择、测试集或资产版本。先取消运行任务再清除。测试集可以单独删除，既有任务仍保存其冻结副本。损坏记录会保留并提示；损坏 AI 设置不会阻止原配置管理，修复时先保留原文件副本。

## 样例与两版试跑

在工作台下方“试跑与迭代”点击“AI 生成测试样例”，或手动新建。AI 草稿须核对覆盖面、事实参考及检查标准，可编辑输入、分组、参考、确定性检查、语义评分标准和阈值。编辑后先保存才能试跑。最多 20 个测试集，每集 1–12 条；保存带修订号，冲突不会覆盖另一窗口的修改。

生成样例会发送当前草稿、候选及目标。试跑固定当前草稿与所勾选候选的完整补充段和共享规则，不切换全局启用项。两版使用同一测试模型、推理强度、温度（可留空使用宿主默认）、输出上限和共同背景；实际协商参数变化会停止对比。结果中可查看每例原始输出、检查、得分依据、延迟与实际用量。

确定性检查包含包含/不包含、完全一致、开头、合法 JSON、必需字段和字符上限。语义评分使用固定标准与参考，随机 A/B 顺序并隐藏候选身份，显示分别评分的理由。评分仍可能有偏差，不能把助手自述“成功”作为执行证据。调用或评分失败算不完整，不算通过。少于三条保留样例或重复使用保留集时，明确标为探索性结果。

## 预算内优化

至少保留一条训练样例和一条独立保留样例。优化先跑训练对比，根据失败改写，再验证训练效果；改写模型只接收训练输入与结果，不接收保留样例输入、参考、评分或输出。选出的最佳候选最后与原稿在保留样例上各跑一次；不会依据保留结果继续改写。

默认最多 24 次调用、2 轮改写，可调到最多 40 次调用、3 轮；整个任务最长 10 分钟，输入总计最多 400000 字节，每次输入最多 120000 字节。目标回答默认每次 1024 输出 Token；改写/样例生成每次预留 4000、评分每次预留 700 Token。输出预留总额最多 24000 Token，派发前按上限累计，不能因前一响应较短就假定后续免费。服务内部重试及最终计费仍由供应商决定。

只有训练和保留结果均完整、平均分不退步、没有已通过确定性检查退步，并至少有一组平均分提高，才提供优化候选；否则保留原版。达到预算、取消、异常或中断时保留已有结果，不能采用不完整候选。优化候选另存时锁定已试跑的规则顺序，改变选择应重新试跑。所有候选都需要人工审阅和显式保存，保存后仍不自动启用。

## 从明确反馈学习与整理规则

操作选择“从会话或反馈学习”，展开来源，先读取会话列表、预览，再勾选 1–12 条可见消息。也可手动填写较早会话 ID。只取最后 60 条有文本的用户/助手消息，每条最多发送预览的前 6000 字，合计最多 60000 字节。发送前按 seq 和完整原文哈希核对，消息变化须重新预览。工具结果、推理、未选消息和进程组装快照不会作为聊天反馈带入。

助手陈述和来源依据仍需核实，模型应区分长期纠正、项目事实和一次性任务。没有会话服务时可粘贴材料；没有无人值守学习或自动应用。

规则库“去重与修剪”显示相同正文、未引用项和所有受影响配置。选至少两条可让 AI 提议合并，显示替换的引用；采用时新建规则，只改变新方案引用，不覆盖或删除旧规则。停用需确认影响，会影响所有引用配置；删除仅允许未引用规则，并核对数据与单项版本。语义重复和冲突由人审阅，程序不会凭模型建议自动删库。

## 版本记录与恢复

配置菜单“版本记录与恢复”查看每次资产保存之前/之后的完整图，最多保留最近 30 条且累计不超过 32 MiB。记录正文、附加规则、共享规则的内容、顺序与开关；启用项变化也留存。它不包括设置页的环境/渠道开关，也不追溯安装前的编辑。

默认“另存恢复方案”，可预览各条规则后保存；也可明确确认后替换当前已保存配置，或只另存一条历史规则。已变化的共享规则复制为新项，其他配置继续使用原内容。恢复会形成新版本，不自动切换全局启用项，当前未保存草稿仍保留，需要显式打开或载入。

版本日志使用准备/提交标记，启动读取时只有完整资产后像或已提交链可以证明时才恢复提交状态。日志写入故障不会阻断原保存，面板会提示未保证可回退，仍应保留导出备份；资产原子写失败不会改变内存配置。

## 当前版本边界

0.6.2 包含文本试跑、资产版本和受控反馈迭代。未提供完整 DSH 上下文重放、工具/文件执行评测、按项目或会话自动路由与隔离；启用项仍为宿主进程共享。语义评分不是客观能力证明，真实 Coding Agent 验证需要另建隔离宿主/工作区并检查实际执行证据。没有嵌入 Promptfoo、GEPA 或额外模型 SDK，使用现有宿主服务完成有界编排。
