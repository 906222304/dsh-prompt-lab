# 提示词处理：设置说明

适用于 0.5.4 起的设置界面。旧版名称“运行时上下文过滤”“渠道指纹脱敏”分别对应“环境信息”和“渠道身份句兼容”。改名与重新分组不改变已保存的设置。

## 两项功能的区别

| 项目 | 环境信息 | 渠道身份句兼容 |
| --- | --- | --- |
| 目的 | 控制向模型提供多少宿主环境信息 | 处理特定渠道对已知身份句的文本匹配问题 |
| 操作 | 原样保留、替换具体值、整组移除 | 在命中清单的句子词间插入零宽空格 |
| 范围 | 宿主组装结果中的环境上下文 `contexts` | 提示词段 `sections` 和环境上下文 `contexts` 中命中的文本 |
| 是否隐藏路径等具体值 | “隐藏具体值”按规则替换；“整组移除”不提供这组内容 | 不负责隐藏这些值 |
| 默认值 | 原样保留 | 关闭 |

两项可以独立使用。若同时开启，先处理环境信息，再处理仍存在的已知身份句。例如“隐藏具体值 + 渠道兼容”可以同时替换环境地址和处理身份句；只开渠道兼容仍可能保留真实路径。

## 环境信息

宿主会自动附加工作目录、源码路径、Web 界面地址，以及沙箱、审批等环境/策略说明。这些信息与用户编写的提示词、附加规则和聊天记录是不同来源。

### 原样保留

默认选项，不替换、不移除该组环境信息。模型可读取真实目录、地址和宿主说明。

### 隐藏具体值

按内置匹配规则，将环境信息中的路径、HTTP(S) URL 和 ISO 时间戳替换为占位符，保留句子结构与功能说明。例如：

```text
工作目录：D:\work\demo          → 工作目录：<路径>
界面：https://example.com      → 界面：<URL>
时间：2026-11-07T10:00:00Z    → 时间：<时间>
```

路径规则包括 Windows 盘符/UNC 路径，以及实现中列出的 Unix 目录前缀；它不是任意路径或秘密的通用识别器。不应据此认为 API Key、所有 IP、个人信息或完整对话都已清理。

### 整组移除

将这整组环境信息移除，工作目录和其中的沙箱、审批说明也一起不再提供给模型。这可能影响模型判断与操作方式，但不会修改宿主实际权限、文件沙箱或审批机制。

### 处理边界

- 此选项不改写提示词正文和共享规则，不清理聊天消息、工具输出或整个会话。
- 官方以单独消息形式注入的时间信息不在此范围。
- 本插件不改写已保存的提示词原文、已有消息或历史轨迹。
- 后续宿主/插件仍可能追加或处理其他信息，因此观察结果不等于模型 API 最终请求。

## 高级兼容性 → 渠道身份句兼容

默认关闭，入口默认收起；摘要显示已保存的实际开关状态。升级不会把已有开启状态重置为关闭。

### 适用场景

针对已知的 WorkBuddy `400 / 11128` 身份句匹配问题提供兼容处理。该报错可能有其他原因，不能仅凭状态码认定一定需要开启；本功能不保证解决所有渠道拒绝、鉴权、配额或网络问题。正常调用无需开启。

### 实际处理

在内置清单命中的句子中，向词间插入不可见的 U+200B 零宽空格，改变连续文本的匹配形式，不删除整句。实际发送的字符串会改变；不能据此保证分词或模型行为完全不受影响。

目前匹配的类型为：

- `You are a coding agent powered by … model.`
- `You are an AI agent powered by DeepSeek Harness.`
- `You are interacting with the user through the DeepSeek Harness Web GUI` 前缀。
- `DeepSeek Harness implementation checkout` 和 `DeepSeek Harness Web GUI URL` 来源说明。

清单来自项目已有兼容实现，只处理命中的片段，不是对所有身份信息的自动识别。

### 不等同于隐私保护

此开关不负责替换路径、地址、API Key 或聊天内容，不隐藏网络 IP，不改变模型能力或宿主权限。历史消息中已出现的身份句不会回改，内置清单以外的内容不会处理。

## 保存、生效与核对

- 这些设置由同一 DSH 数据目录共用，不属于某一套提示词配置，切换配置不会切换设置。
- 修改后自动保存到 `DSH_HOME/prompt-lab/settings.json`，重新打开仍保留。保存失败时保留先前值并显示错误。
- 只影响之后的新组装；正在进行或已经保存的请求不会重写。
- 发送一次新请求后，在“设置 → 诊断”核对最近观察。注册成功、设置已保存都不等于模型已收到。
- 诊断只保存进程最近一次观察，可能来自其他会话。过期提示表示配置/设置已变化，应等待新请求。
- “本次身份句处理”的数量是发生改写的提示词段/上下文条目数，不是关键词数量；一个段匹配多句仍计为一个段。零命中不代表开关关闭。
- 本次“去除 0 条”也不代表未执行“隐藏具体值”：替换内容不会减少条目数，应结合观察模式理解。

## 接口兼容

界面改名后底层字段仍为 `contextFilter: off | redact | strip` 和 `identityBreak: boolean`；没有迁移或重置设置文件，没有变更文本处理算法。
