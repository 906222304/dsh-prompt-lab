# 0.6.4 本地候选版交付记录

日期：2026-11-07（Asia/Hong_Kong）。基线：0.6.3 / `13ed8cb9bfb647683a69c7dc4751231f818a3c98`。

本版完成当前会话范围、材料到应用的步骤衔接，以及完整资产包和过期场景更新。没有接入 Promptfoo，也没有新增上游补丁依赖。使用方式见 [工作流与资产指南](assets-guide.zh-CN.md)。

## 验收

- 139 项 Node 测试、plain 入口及 43 个 JavaScript 文件语法检查。
- Chromium + React 18 DOM 完成旧功能回归、A/B/空白会话切换、迟到元数据、双面板、各自草稿/材料/任务隔离、绑定目标衔接；完整资产下载/上传/预览/追加和待适用记录；过期场景差异与另存。25 次合成模型调用，不涉及用户资产或真实费用。
- 明暗主题 1200/520/360px，新增资产卡 1200/360px 无横向溢出；人工查看代表截图。
- 真实 DSH 0.2.2-rc.1 的隔离 Cordis/SystemPrompt/WebServer/SessionStore/SessionQuery 联调；实际归档解包运行、导入中断恢复/重试、依赖场景往返、场景更新，以及与实际 0.6.3 包的降级兼容和完整数据备份恢复。

各项最终结果、包大小与 SHA-256 记录于 release-0.6.4-manifest.json；该清单是本地验收快照，Git 提交与远端状态以实际 refs 为准。

## 数据与回退

profiles.json 仍是 schemaVersion 2；设置格式不变。旧测试集 v1/v2 继续支持。省略额外失败原文的测试集采用 v3 来源摘要，0.6.3 无法读取 v3；保留 0.6.3 包和升级前整个数据目录才能完整回退。0.6.3 可以读取原 v2 和原会话绑定。导入日志恢复未完成时阻止通过接口读取不完整资产；外部编辑冲突需先保留现场并核对完整备份。

资产包导入不自动启用、绑定、执行任务或调用模型；已导入任务只能只读查看。当前目录仅为会话初始目录；范围预览不等于最终 API 请求。

## 运行状态

当前活动实例固定在已实际验收并由用户重载的 0.6.3，原数据已恢复，详见 [运行验收记录](runtime-acceptance-0.6.3.md)。0.6.4 是本地候选包，未替换活动实例、未提交推送或发布 npm。原生 Windows 桌面点击仍因工具沙箱初始化失败未验收；浏览器、原生模块与当前 HTTP 证据分别列示。
