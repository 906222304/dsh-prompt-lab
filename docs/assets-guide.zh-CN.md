# 0.6.4 完整资产包、会话范围与场景更新

## 当前会话

顶部“当前会话”来自宿主 conversation 视图的 sessionId，不按最近会话、组装快照或最后访问目录推测。缺少宿主身份时，点击“选择目标会话”明确指定；空白页签不会继承此前手选目标。

范围卡展示全局配置或固定快照的名称、版本、引用规则数和原资产更新提示。绑定文件不可读时标为阻断。插件未启用、段服务未注册会另外提示。它说明下一次组装的配置选择，不证明模型 API 最终请求。

目录来自会话初始 header；会话内 cd 后的当前目录未核实。项目规范扫描前应核对路径。环境过滤、渠道设置仍是全局设置；底栏“全局默认”用于未绑定会话。

A/B 会话各保留自身编辑草稿、创作材料、目标和历史筛选。切换会话会卸载当前工作台，未提交的消息勾选、文件选择和预览需重新核对。已派发任务可以继续运行，只在原目标会话恢复；后端禁止跨目标继续改写或试跑。空白视图中的旧任务不被自动归入当前会话。

## 材料到应用

1. 选择项目规范、粘贴材料或显式预览反馈消息。项目文件预览后可点“使用所选规范提取规则”，只切换操作，不自动调用模型。
2. 明确生成候选；核对正文、规则和来源，再选测试集试跑。失败回归先确认来源与评分标准，保存后可直接作为训练集；独立保留样例仍需另备。
3. 采用为已保存方案后，可点“预览绑定到当前目标会话”。预览完整快照并确认后才绑定。保存方案不会自动启用，绑定不会改变全局默认。

## 完整资产包

“导入导出”顶部是完整资产包；下方保留旧的“配置与规则 JSON”通道，旧格式语义不变。两种格式使用各自文件入口。

可选择配置、共享规则、测试集、场景、绑定适用记录，以及可选的额外来源原文与任务证据。选中场景或绑定时自动携带其冻结依赖，因此取消“配置”不代表包中一定没有依赖配置。导出预览列出最终数量及完整 JSON，核对后下载。

测试集本身包含用户输入、参考答案、评分标准。额外原文默认关闭，去除失败回答、来源消息正文和任务输出，失败来源保留不可执行的摘要与哈希。开启后会携带额外失败原文、所选项目/会话材料和终结任务结果。配置/规则正文以及用户主动写入的测试内容始终属于所选资产，不承诺自动识别其中的秘密。

不读取宿主供应商凭据；模型路由只保留 provider、model 和受支持参数。运行中任务不导出；终结任务导入为只读证据，不恢复为可执行任务或候选。

导入先显示各类型数量、依赖配置、模型引用可用性和原文范围。确认后追加新 ID，原资产、全局默认、已有绑定保持原样。导入场景中的旧配置/规则快照被重新映射为独立资产；不会悄悄指向目标实例同名配置。导入测试集的独立性未核实，保留集至少计一次使用，结果按探索性解释。

绑定记录导入为待适用提示，原会话 ID 仅为来源说明。点“读取已导入适用记录与证据”，再选择会话、预览、确认；另一个实例上相同字符串的会话也不会自动绑定。模型缺失或目录无法核实时保留资产，载入场景前需重新核对或另存更新。

同一已提交预览重试不会重复追加。重新预览后再次导入属于新的追加副本。预览 20 分钟过期，服务重载或目标资产变化后需重新预览；已经提交的凭据仍可识别重试。

## 中断与容量

资产包最大 32 MiB；每包最多 20 配置、50 规则、20 测试集、10 场景、20 绑定提示、20 只读证据，目标存量同样受上限约束。依赖也计入上限，超限需减少类型或先整理资产。

导入采用预写事务日志，先写依赖再写核心索引。中途退出后，下次接口读取/插件初始化前检查哈希并补齐全部写入；外部编辑冲突时停止恢复并保留记录，不提供半套资产供使用。不要手工删除未完成的 studio/imports 事务；先保留完整目录并核对备份。

这是进程中断恢复协议，不承诺存储硬件断电时的绝对持久性。多个 DSH 进程同时写同一数据目录不受支持；不要在外部修改目录的同时导入。

## 场景更新

试跑区展开“场景方案”，选择旧场景后展开“查看源变化并另存更新场景”。选择最新已保存配置/测试集，原项已删除时明确选择替代项。默认保留旧场景模型、完整预算与共同背景；勾选后才使用当前试跑参数。

“查看更新差异”列出配置、规则正文/顺序、测试集修订及参数变化。确认另存前再次核对来源哈希；预览后发生编辑会被拒绝。旧场景保留，新场景不继承旧评测分数，也不自动载入、启用或调用模型。

## 版本和完整回滚

核心 profiles.json 仍是 schemaVersion 2，旧测试集 v1/v2 可继续读取。没有额外原文的失败来源测试集使用 v3 摘要；0.6.3 不支持 v3，但支持原有 v2。回退前备份整个 DSH_HOME/prompt-lab 和当前版本包，再恢复成对的基线目录与安装包。仅导出配置/规则不足以完整回退，便携资产包也不包含活动绑定、全部版本历史或运行状态。
