交付日期：2026-11-07（Asia/Hong_Kong）。本版重做前端布局与视觉，沿用 0.5.1 的配置、规则及存储能力。

## 设计参考与改动

参考开源 [yetone/magpie](https://github.com/yetone/magpie/tree/f9a88c4fbeec771f71f2d05fbb77ce1a6239d035)，
固定参考提交 `f9a88c4fbeec771f71f2d05fbb77ce1a6239d035`：浅灰背景、白色分组卡片、暗色对应层级、
紧凑导航、分组列表与胶囊开关。参考项目使用 MIT 许可；本版 CSS、React 布局和 SVG 图标独立编写，未复制品牌资产。

- 提示词与规则：左侧可搜索配置列表，右侧编辑；配置管理菜单集中新建、复制、改名、导出、删除。
- 正文、可折叠附加规则和有序共享规则分组；预览与运行信息默认收起，编辑卡片内滚动，保存按钮保留在卡片底部。
- 规则库：列表与编辑分栏，危险或低频操作收进“更多操作”。
- 导入导出：备份与导入分别成卡，预览与提交保持原流程。
- 设置与组装快照：统一卡片、字段、状态与文字层级，保留快照作用域、截断和过期说明。
- 明暗主题使用宿主语义变量并提供灰阶回退；1200、520、360px 布局适配。

API、正文/规则段顺序、数据 schemaVersion 2、草稿保护和版本冲突协议保持原有行为，无新增运行依赖。

## 回滚到 0.5.1

1. 保留当前 profile manifest、patch 和 `DSH_HOME/prompt-lab` 数据副本。
2. 使用宿主插件管理或官方 CLI 将依赖切到保留的 0.5.1 tgz，重新加载两条插件行。
3. 验证 API 返回 0.5.1、配置与规则数量正确、前端恢复旧版。

两版使用同一数据结构，单纯回滚本次界面改版不要求恢复旧数据。只有要撤销用户后续编辑时，才恢复同一时间点的数据备份。
回滚到 0.4.9 仍须遵循 [0.5.1 的数据恢复步骤](release-0.5.1.md#回滚步骤)。
