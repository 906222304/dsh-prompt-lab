# 0.6.2 开发检查点

日期：2026-11-07。当前包版本仍为 0.6.0，本文记录未完成的开发代码，不作为 0.6.2 发布或验收记录。

已加入的基础代码：

- 资产保存前后快照、完整规则图恢复，以及规则引用分析和维护函数。
- 测试集存储、修订号、训练/保留样例分组与确定性输出检查。
- 显式选择会话消息的读取适配器和内容哈希校验。
- 文本对比和有限轮次优化的实验编排草稿。

尚未完成：

- 实验模块接入任务执行器、预算计数、取消和路由一致性校验。
- HTTP 接口、前端测试集编辑、对比结果、版本恢复与会话选择流程。
- 反馈学习和规则合并候选的完整生成、审阅、采纳流程。
- 新能力的全面异常测试、真实浏览器及宿主验收、正式打包和部署。

现有资产保存路径已接入版本日志；日志不可用时保存会返回 `historyWarning`，前端尚未展示该字段。会话读取适配器是可选注入，目前没有新增会话读取 HTTP 入口。

验证：`npm run check`、`npm run test:plain`。新增基础测试只覆盖快照恢复、规则删除保护、测试集修订冲突和消息选择，不能代表实验编排已验收。0.6.0 发布基线仍以 `docs/release-0.6.0.md` 为准。
